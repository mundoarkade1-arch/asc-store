# Instruções para agentes
- Projeto estático sem build. Não adicionar frameworks. Functions só em functions/ (admin e API).
- Paleta oficial: #101010, #C8FF00, #FFFFFF. Não criar novas cores de marca.
- Apps só em data/apps.json. Nunca inventar links de download.
- Escapar todo texto vindo do JSON (função esc em js/app.js).
